## Problem

Generate coordinated two-person motion that keeps a shared object stable.

## Key Idea

!!! tip
    Use object stability as the organizing constraint for cooperative motion.

## Input / Output

Shared object trajectory/context → coordinated human–human motion.

## Method

Stability-aware guidance shapes a conditional motion generator.

## Dataset

CORE4D

## Contribution

Links interaction synthesis with task-level cooperative stability.

## Limitation

Designed around co-manipulation and may not generalize to broader social motion.

## Embodied AI Relevance

!!! success
    Very high: immediately relevant to human–robot collaborative carrying.
