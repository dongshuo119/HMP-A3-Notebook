## Problem

Scale dynamic 3D HOI generation across more objects and actions.

## Key Idea

!!! tip
    Build a versatile HOI dataset and jointly model human and object motion.

## Input / Output

Text/object condition → human–object motion sequence.

## Method

A joint generative model captures coupled body and object dynamics.

## Dataset

InterAct

## Contribution

Broadens data scale and interaction diversity for HOI generation.

## Limitation

Dataset object and interaction coverage remains finite.

## Embodied AI Relevance

!!! success
    Very high: coupled agent–object dynamics are central to manipulation.
