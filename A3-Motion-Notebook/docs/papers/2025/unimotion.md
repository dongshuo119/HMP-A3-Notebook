## Problem

While existing works control avatar motion with global text conditioning, or with fine-grained per frame scripts, none can do both at once. In addition, none of the existing works can output frame-level text paired with the generated poses.

## Key Idea

We introduce Unimotion, the first unified multi-task human motion model capable of both flexible motion control and frame-level motion understanding.
